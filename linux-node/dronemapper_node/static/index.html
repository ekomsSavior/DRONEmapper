Radio settings

Dedicated adapters, fixed channels. Keep your Internet radio separate.

ADS-B uses 1090 MHz and requires readsb. DJI uses HackRF and the DJI extra; one channel, with reception gaps while processing. One SDR runs one mode at a time; Wi-Fi and Bluetooth keep listening. RTL-SDR cannot directly receive 2.4 or 5 GHz.

Station location & sharing

Exact station coordinates stay here. Positions on the radar use aircraft-reported GPS.

Fresh DJI DroneID positions and ADS-B B6-category broadcasts qualify; ordinary aircraft and recordings stay local. Broadcast identity is unverified.

Area sharing publishes a 0.01° receiver grid cell, not an exact drone position. Radio MACs and network names remain local.

Existing ADS-B receiver

Leave blank when this node starts readsb. A fresh local feed can run alongside a separate SDR spectrum receiver. ADS-B aircraft stay local; UAS category is a broadcast claim.

Optional MQTT receiver feed

Use a broker and exact topic you are authorized to receive. Remote connections require TLS. Accepts the documented Remote ID envelope, not arbitrary fleet messages.
