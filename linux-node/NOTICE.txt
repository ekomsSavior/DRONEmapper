The Python protocol parser is an independent implementation of the public ASTM
F3411 protocol-v2 wire format. Layout references:
https://github.com/opendroneid/opendroneid-core-c
libopendroneid/opendroneid.h, opendroneid.c, wifi.c (Apache-2.0 upstream).
The GPL-2.0-only Android application is a separate component; its code is not
included in this Python package.

rid-catalog.json contains factual FAA Declaration of Compliance manufacturer,
model and serial-range fields exported from this repository's worker catalog.
https://uasdoc.faa.gov/listDocs
Declarations and broadcast identifiers are not independent authentication.

oui-vendors.tsv contains IEEE MA-L, MA-M, MA-S and IAB allocation facts from
Ringmast4r's OUI Master Database. See oui-vendors-provenance.json for revision,
selection and SHA-256. No device-type heuristics are imported. A radio vendor
is not necessarily the manufacturer of the complete drone or robot.
https://github.com/Ringmast4r/OUI-Master-Database
https://standards.ieee.org/products-programs/regauth/

Optional separately installed dependencies/tools retain their own licenses:
Bleak (MIT), Eclipse Paho MQTT Python (EPL-2.0 / EDL-1.0), BlueZ, Wireshark
dumpcap, HackRF tools and Osmocom rtl-sdr. They are not bundled in this package.
pySerial (BSD) is an optional separately installed serial-port dependency.
The stock Marauder RID CSV layout was inspected in Just Call Me Koko's
ESP32Marauder project at commit 45f47daa6ae65b36bbef9f9051977adcb315b1c5,
esp32_marauder/WiFiScanRemoteId.h. The serial parser is independent code;
no Marauder firmware or implementation is redistributed in this package.
https://github.com/justcallmekoko/ESP32Marauder
The root repository NOTICE.txt covers other website data sources.

The optional DJI receiver includes receive-only demodulation helpers derived from
RUB-SysSec/DroneSecurity (NDSS 2023), AGPL-3.0, revision
9ff819843bee48fb140a0704ec78aff757896dea. Its LICENSE and per-file provenance are
in dronemapper_node/_vendor/dronesecurity/. Models are broadcast code mappings,
not authenticated identification. No upstream recordings are distributed.
The optional dji extra uses NumPy (BSD), SciPy (BSD), Matplotlib (PSF-based) and
bitarray (PSF). These libraries are installed separately.
readsb (GPL-3.0) is a separate receiver process, built by the optional setup script
at revision 8afcc22de2de81be38231695285070603af78ef4. Its source/license remain in
the installation source directory; no readsb binary is bundled.
