ROOTLESS USB WI-FI DRIVER
The files under app/src/main/java/net/kismetwireless/android/pcapcapture/
are adapted from Android PCAP:
https://github.com/gnyman/AndroidPCAP
Git tree: 00410fec5c7edae8eb44eb0a0d481b3bf2e578c2
Original project: https://www.kismetwireless.net/static/android-pcap/

Java/Android conversion: Mike Kershaw / Dragorn.
Derived from MacUserspaceWifi and Linux RTL8187 drivers.
Original driver copyrights: Michael Wu (2007), Andrea Merello (2005, 2007),
and contributors. Additional Android PCAP work: Jinghao Shi and gnyman.
Rtl8187Card.java retains the upstream copyright and GPL v2 notice.

Changes for this local build: narrowed USB ID support to RTL8187L 0bda:8187;
removed JNI/libpcap logging dependency and raw packet dump helper; closed USB
connections on shutdown; failed initialization stops capture; TX command bits
disabled; RX descriptor lengths and CRC/ICV flags checked; uncalibrated RSSI
omitted. The application only retains decoded Remote ID beacon information.
These changes are experimental and have not been tested on physical hardware.

REMOTE ID RESEARCH
The new RidDecoder is an independent subset implementation of the public
OpenDroneID wire format. Protocol references:
https://github.com/opendroneid/opendroneid-core-c
https://github.com/opendroneid/receiver-android
The test vectors were generated using opendroneid-core-c commit
849c03adbe0cdd68997a462fafab397edcfe53f3 (Apache-2.0). That library and the
synthetic vectors are not linked into the Android application. No DroneAware
code, paid data feed or account access is used.

MEDIATEK ROOTLESS USB RECEIVE DRIVERS (2026-10-17)
app/src/main/cpp/uwifi is adapted from Kismet's userspace USB Wi-Fi layer:
https://github.com/kismetwireless/kismet/tree/e3d31f3275484f8b3d4cc56a5893a4fcf964585d/capture_userspace_usb_wifi
Copyright Mike Kershaw / Kismet contributors; GPL-2.0-or-later for its wrapper.
Vendored Linux driver and wireless headers retain their original copyright and
SPDX notices (GPL-2.0-only, ISC, BSD variants as marked in each file).
The added drivers/mt76/mt76x0 directory is from Linux v6.18:
https://github.com/torvalds/linux/tree/v6.18/drivers/net/wireless/mediatek/mt76/mt76x0

DRONEmapper modifications: Android libc/header compatibility; getrandom syscall
for API 26; Android-granted USB file descriptor entry point; USB serial reads
omitted; JNI receive callback and frame counts; no packet transmit API exposed;
MT7610U added to the userspace driver build. Sources and build script are included.
Native drivers compile for arm64-v8a, armeabi-v7a, and x86_64. Compilation does
not establish physical adapter reception; see docs/usb-scanner-testing.md.

app/src/main/cpp/libusb: libusb 1.0.29, LGPL-2.1-or-later; see its COPYING.
https://github.com/libusb/libusb/releases/tag/v1.0.29
The full corresponding source used for the Android library is included.

Hardware firmware is redistributed unmodified under the separate Ralink / MediaTek
binary redistribution license, bundled in assets/usb-firmware. It is firmware for
the adapter, not open-source app code. mt7662 firmware comes from pinned Kismet
above; mt7610u.bin comes from Ubuntu linux-firmware
20240318.git3b128b60-0ubuntu2.27 (decompressed unchanged from its .zst container).
Checksums and provenance: app/src/main/assets/usb-firmware/provenance.json.
