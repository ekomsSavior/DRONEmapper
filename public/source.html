Run the map locally

Clone a repository or extract the ZIP. With Python 3.10+ installed, open a terminal in the project folder and run:

python3 server.py

Then open http://127.0.0.1:8780. On Windows, use py -3 server.py. Keep the server running for five-minute updates. No extra packages, API keys or receivers.
